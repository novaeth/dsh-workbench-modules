# 更新日志

## v0.3.1

`2026-11-24`

### 修复

- 文案键改用模块标识前缀（`creator-daily.*`），否则工作台不合并词表，卡片会显示裸键名
- 小红书概览的周期参数改成 `seven`（opencli 只认 `seven` / `thirty`）
- 某个平台读到空列表时，卡片会写明「没有读到内容（可能未登录）」，不再静默空着

## v0.3.0

`2026-11-24`

### 变更

- 声明四个站点由 opencli 自带（`sources: [{ "kind": "builtin" }]`）：市场与工作台会核对当前 opencli 是否真的有这些命令
- 运行要求提到 `@dsh-workbench/core ^1.5.2-rc.0`（支持 builtin 来源的版本）

## v0.2.3

`2026-11-24`

### 修复

- 恢复 `bin: opencli` 依赖声明：opencli 由适配器提供，不是工作台自带，模块跑平台命令前要能查到它

## v0.2.2

`2026-11-24`

### 修复

- 不再把 opencli 声明成依赖：工作台里 opencli 是自带的运行时，声明成 bin 依赖会让市场报「缺少依赖」；缺 opencli 时改由卡片的读取失败说明

## v0.2.1

`2026-11-24`

### 修复

- 去掉知乎、微博、B 站、小红书四条扩展依赖：它们是 opencli 自带的站点，不单独安装，声明出来会让市场报「缺少依赖」

## v0.2.0

`2026-11-24`

### 新增

- 今日选题：读取知乎、微博、B 站热榜
- 笔记数据：读取小红书概览指标与最近笔记
- agent 工具：`creator-daily_topics`、`creator-daily_notes`、`creator-daily_save_draft`
- 存草稿前显示审批屏
