# @dsh-workbench/module-creator-daily

内容创作者的一天：今日选题、笔记数据与草稿。

当前版本（0.1.0）只有一张模块卡片：没有数据源，也没有给 agent 开放工具。

## 你会看到什么

右侧面板多一个「内容日更」模块。模块里列出这条工作流的三个部分，并说明当前版本没有接入数据源。

模块之外没有界面：没有设置项、没有审批、没有 agent 工具。

## 安装

模块市场发布之前，先在仓库里构建：

```bash
pnpm install
pnpm -r build
```

构建结果里，`dist/host.js` 是宿主入口，`client.js` 是浏览器入口。

## agent 能做什么

当前版本没有开放工具，agent 看不到这个模块。

计划中的能力：

| 能力 | 数据从哪来 | 是否需要批准 |
|---|---|---|
| 今日选题 | 知乎、微博、B 站热榜 | 只读 |
| 笔记数据 | 小红书创作者中心 | 只读 |
| 存草稿 | 小红书草稿箱 | 需要批准 |

## 数据从哪来

三个热榜与小红书创作者中心都从浏览器里已登录的会话读取。模块不保存账号与密码。

登录过期时，模块要能区分「需要登录」与「没有数据」。

## 审批

存草稿会先显示审批屏，列出四项：对象（哪个平台、哪条内容）、修改内容、目标位置、影响范围。

## 已知限制

- 发布使用平台页面的自动化操作，平台改版后可能失效。
- 标题最多 20 字，图片最多 9 张。
- 只存草稿；正式发布需在平台完成。

## 手工验收

1. 在浏览器登录知乎、微博、B 站与小红书。
2. 打开工作台，勾选「内容日更」模块。
3. 确认模块显示三个热榜条目。
4. 让 agent 读取选题，确认内容与模块一致。
5. 让 agent 存一条草稿，核对审批屏内容；批准后到小红书草稿箱查看。
