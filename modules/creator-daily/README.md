# @dsh-workbench/module-creator-daily

内容创作者的一天：今日选题、笔记数据与草稿。

## 你会看到什么

右侧面板多一个「内容日更」模块，分三块：

- **今日选题**：知乎、微博、B 站热榜的前 5 条，带排名与热度。
- **笔记数据**：小红书创作者中心的观看、点赞、收藏、评论与趋势。
- **最近笔记**：最近 3 篇笔记的观看与点赞。

卡头有刷新按钮；读不到时模块会说明是哪个平台、什么原因。

## 安装

在模块市场安装后，在右侧面板的「面板模块」里勾选「内容日更」。

先决条件：

- 浏览器里已登录知乎、微博、B 站与小红书。
- 机器上装有 opencli（工作台会提示安装方式）。

## agent 能做什么

| 工具 | 做什么 | 是否需要批准 |
|---|---|---|
| `creator-daily_topics` | 读取三个热榜，返回排名、标题、热度与链接 | 只读 |
| `creator-daily_notes` | 读取小红书概览指标与最近笔记 | 只读 |
| `creator-daily_save_draft` | 把一条图文笔记存进小红书草稿箱 | 需要批准 |

存草稿的审批屏列出四项：对象、修改内容、目标位置、影响范围。

## 数据从哪来

三个热榜与小红书创作者中心都从浏览器里已登录的会话读取。模块不保存账号与密码。

登录过期时，模块会写「需要登录」，而不是显示 0 条。

## 已知限制

- 发布使用平台页面的自动化操作，平台改版后可能失效。
- 标题最多 20 字，图片最多 9 张，超出时工具直接报错。
- 只存草稿；正式发布需在平台完成。

## 手工验收

1. 在浏览器登录知乎、微博、B 站与小红书。
2. 打开工作台，勾选「内容日更」模块，确认三块都有内容。
3. 让 agent 读一次选题，确认条目与模块一致。
4. 让 agent 存一条草稿，核对审批屏内容；批准后到小红书草稿箱查看。
